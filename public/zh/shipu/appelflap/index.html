荷式苹果酥角

苹果酥角属于荷兰丰富的单人份甜点面包传统，与「汤波斯」和「摩尔科普」等亲缘糕点一样，几个世纪以来一直在街角小面包店的橱窗中出售。这道食谱的简单——千层酥皮、苹果、葡萄干和肉桂——反映了十九世纪荷兰厨房中这些食材的普及程度，当时苹果是全年最常见、最容易获得的水果。 与整个荷兰苹果派不同，苹果酥角被设计成单人份，便于边走边用手吃，适合荷兰城市繁忙的都市生活。如今它仍是每家传统面包店的必备品，常常在早晨新鲜出炉，搭配咖啡作为早餐或午间点心。

折叠成三角形

千层酥皮切成方形，包住馅料折成三角形，再把边缘牢牢压紧。

🍎

酸苹果粗切

酸苹果切成大块而非磨碎，烤后能保持口感，而不会变成果泥。

🍇

馅料中的葡萄干和肉桂

在温水中泡发的葡萄干和肉桂粉直接与苹果混合，不添加其他调味料。

☀️

在面包店新鲜出售，不只是家庭制作

虽然在家制作很简单，苹果酥角仍与街角面包店紧密相连，人们常常直接从橱窗买新鲜出炉的热腾腾的酥角。

食材 4份

  • 1张冷冻千层酥皮
  • 4个酸苹果，去皮切块
  • 50克葡萄干
  • 2汤匙糖
  • 1茶匙肉桂粉
  • 1汤匙柠檬汁
  • 1个鸡蛋用于刷面
  • 糖粉
  • 一撮盐

做法

  1. 1将千层酥皮在室温下解冻二十分钟.
  2. 2在碗中将切碎的苹果与葡萄干、糖、肉桂粉、柠檬汁和盐混合.
  3. 3用锋利的刀把酥皮切成四个相等的方块.
  4. 4在每个方块中央放一份慷慨的苹果馅料.
  5. 5将每个方块对折包住馅料成三角形，用叉子紧压边缘将其封口.
  6. 6打散鸡蛋，用糕点刷在每个三角形表面刷上蛋液.
  7. 7以200°C烤二十五分钟，直到金黄蓬松，上桌前撒上糖粉.
